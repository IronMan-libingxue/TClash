# 技术栈与构建资料

## 当前 B 端 · TClash 2.5.12

- 源码见 [source/tclash](../source/tclash)。完整 2.5.12 源码用 [source-v2.5.12](https://github.com/IronMan-libingxue/TClash/tree/source-v2.5.12) 固定。基于 FlClash v0.9.3，使用 Flutter/Dart 桌面界面、Mihomo 内核和平台的代理服务。该轮本机构建采用 Flutter 3.47.6，Dart 范围由 `pubspec.yaml` 声明。Mihomo、界面组件的上游提交固定在 Git 子模块。
- macOS 使用 Xcode 与 Installer。包脚本见 [macos-upgrade.sh](../source/tclash/tools/release/macos-upgrade.sh)。Apple 芯片和 Intel 分开构建。原交付的应用使用本地签名，包未经 Apple 公证。
- Windows 由 Mac 构建，使用 Windows Flutter 引擎与运行库、LLVM、cargo-xwin、Windows SDK 和 Inno Setup。交付的 Windows EXE 包含桌面程序、采集器和运行库。CrossOver 用于本机隔离验证。[构建工作区留存的 Windows 源码差异](../source/构建差异/windows)用于复查发布路径和编译适配。
- 核对历史安装包可用 [Releases](https://github.com/IronMan-libingxue/TClash/releases) 中的 SHA256SUMS。工具和上游依赖版本应按构建记录重装并先完成一次新构建，再移除现有可用工具环境。

## 独立 A 端与早期 Preview

- 当前 A 端采集器见 [source/preview/codex-collector](../source/preview/codex-collector)，Go 版本要求由 `go.mod` 声明。含计价、用量聚合、密钥验证、设备安装包模板生成与同步逻辑。更早的独立工具源码在 [source/usage-tracker-early](../source/usage-tracker-early)。
- Preview 使用 Clash Verge Rev 2.5.10 的 React/TypeScript、Tauri/Rust 和 Mihomo。原构建记录固定 Rust 1.99.1 和 pnpm 12.16.1，Windows 构建用 cargo-xwin。恢复时应选择 [2026-11-13 源码标签](https://github.com/IronMan-libingxue/TClash/tree/preview-20261113-accepted) 或较后的 [Preview 源码标签](https://github.com/IronMan-libingxue/TClash/tree/legacy-preview-source)。
- 公开价表快照、价表差异、参考美元估算、Fast 费用规则及预算口径见 [A 端设计与验收](设计与验收/04-A端用量计价与通知.md)。

还原已预编译的旧程序只需下载对应发布附件。完整历史构建与实机验收情况见 [开发交接纪要](开发交接纪要.md)。
