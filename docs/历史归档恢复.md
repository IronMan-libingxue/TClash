# 恢复历史安装包和应用

1. 在 [历史制品索引](历史制品索引.md) 找到需要恢复的编号，下载该条目的加密分卷和对应索引。V001–V151 使用 `TClash-history-index.tar.zst.gpg`。V152–V168 使用 `TClash-history-supplement.tar.zst.gpg`。
2. 取用原 Mac 「资源库 → Application Support → TClash Archive」里的 `archive-20261124.key`。这是恢复加密备份的独立钥匙。可另存到安全的离线介质并单独保管。
3. 把附件和解密后的文件分别放在新目录。若某分卷以 `.part01`、`.part02` 等分段发布，请把该卷的所有分段放入同一目录。恢复工具会按顺序读取。运行仓库内的恢复工具，它会验证每一段内容，再核对恢复后文件的原始 SHA‑256。

使用系统上的 Python 3、GnuPG 和 Zstandard。例如还原旧 Windows 1 D 盘修复版：

```sh
python3 tools/restore-history.py \
  --assets /path/to/downloaded-release-assets \
  --key "$HOME/Library/Application Support/TClash Archive/archive-20261124.key" \
  --version V007 --output /path/to/restored-artifacts
```

恢复 V152–V168 时追加 `--index TClash-history-supplement.tar.zst.gpg`。

多数旧设备专用包只适合作历史备份。需要新增设备时，从 A 端生成新的配对包。正在用的桌面数据、配对与授权、代理订阅和 Codex 历史分别由各自运行目录保管。
