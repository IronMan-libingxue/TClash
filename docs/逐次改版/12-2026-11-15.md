# 2026-11-15：Mac 3 标准安装器

- 用户要求交付 Mac 3。A 端只读检查显示 Mac 2、Windows 1、Windows 2 均已接入；Mac 3 原先没有授权。本次用户自行完成 GitHub 身份验证并生成 Mac 3 独立令牌，直接粘贴到 A 端生成设备包，未读取或展示令牌。授权仅限现有用量私库，Contents 读写、有效期 90 天至 2027-02-13；不要撤销其他设备令牌或重新生成 Mac 3 邀请。
- 已生成 `/Applications` 标准安装器：`交付/Mac3标准安装包_20261115/Mac3_TClash_Preview.pkg`。它包含 Mac 3 私人授权，只能私下传送至 Mac 3，不能在 Mac 1 运行。`tools/tclash-mac-pkg/build-package.sh` 现在识别 Mac 2 至 Mac 6 的默认身份，而非固定 Mac 2；A 端内置的后续生成器尚未改为直接输出 `.pkg`。
- 从最终安装器解包后确认 Mac 3 授权与 A 端原发包一致，与待接入邀请、设备令牌登记、仓库、A 的签名验证者和加密接收者匹配，不含 A 端私钥；应用和安装辅助程序均为 Intel / Apple 芯片通用架构，应用临时签名校验通过。模拟新设备接入、同身份重复安装、冲突保护以及安装包标识检查通过，没有在本机执行真实安装或消耗真实授权。
- 与 Mac 2 相同，本机没有有效的 Apple Developer ID 证书，`.pkg` 未签名，应用未公证，macOS 可能提示无法验证；Mac 3 的安装、自动启动及 A 端接收尚需目标设备实测，不能称为已完成实机验收。
