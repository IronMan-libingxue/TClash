# 2026-11-19 本机预览与正式交付

- Mac 发布检查使用带最新 CodeX 图标的 Apple 芯片、Intel 构建。两种包均可由 Installer 解析，包内应用与采集器架构匹配，安装目标为 `/Applications/TClash.app`。用户选择此批不做 Developer ID 分发签名和公证，并指定本机做 Mac 验收。
- A 端本次仍有五台配对设备，Mac 4 与 Windows 1 均有已接收的旧历史，可作为升级前对照。
- TClash 2.5.11 本机预览（旧本地目录） 使用独立标识 `local.tclash.localpreview` 和包内演示用量。本机实点仪表盘、CodeX Speed、周期和缓存开关。预览构建在临时副本中，正式应用和已配对 B 继续使用原有配置。
- 实机升级核对原配对身份、API 令牌、历史和自动连接 A。Windows 实机安装与启动需要观察是否出现黑色运行框。
