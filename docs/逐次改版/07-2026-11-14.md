# 2026-11-14：Windows 1 的 D 盘安装修复（实机成功前的记录）

- 用户反馈：`030747` 和后来的 `033651` 路径修正版在 Windows 1 上均提示安装后找不到程序。用户提供旧版桌面快捷方式的属性，确认实际程序为 `D:\TClash Preview\tclash-preview.exe`。此前把路径修正版交付为待测，并未获得成功反馈；不能再将其视为已修复，也不能把问题归咎于用户操作。

- 在隔离的 Windows x64 兼容环境中，先实际运行了内置安装程序并核对安装文件；又用单独的 D 盘环境、模拟授权和模拟主窗口，执行真正的一键安装器及实际 Windows 采集组件：成功发现并更新 D 盘程序、备份旧文件、加载并消费授权，模拟主窗口未出现控制台。还核对了安装冲突、重装、保留配置等行为；加密传输及 A 接收由内存私库隔离测试验证。这些测试不是 Windows 1 真机、真实 TClash 主窗口或跨网同步验收。
