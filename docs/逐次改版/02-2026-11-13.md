# 2026-11-13：速度归零与说明精简

- 用户确认已经完成 Mac 状态栏双行显示和右键钉住的交互验收；这是用户反馈，Windows 托盘仍未实机验证。
- 普通独立会话处于运行状态时，A 设备卡片显示柔和绿色二级高亮；Fast、多会话及两者并存仍分别为蓝、黄、红并优先于绿色。原有未读用量变化提醒保留。
- 本机可确认没有运行中的会话时，A、TClash 页面与状态栏的模型速度统一显示 `0.00 tok/s`；有运行会话时显示最近可计算的请求速度估算；状态缺失、过期或无法确认时显示未知，不将未知当作 0。A 独立运行时也会只读检查本机会话状态。
- 按用户截图，TClash CodeX Speed 页面删除了参考金额说明，以及代理组采集时间前的“快照统计，可能漏计；跨组流量重复计入”文字；A 端和本交接仍保留统计口径和局限说明。采集逻辑没有改变。
- 用户计划在本机打开两个独立 Codex 会话并让任务重叠，以验证多会话；工具等待算运行，自动子代理不单独计数。此前隔离样本测试不等于用户的实际多会话结果。
- 本轮新版 A 和 TClash 已在本机重新启动，保持独立 A 和原设备数据；TClash 当前可执行文件为 Apple Silicon / Intel 通用构建。真实窗口核对了两处文字删除、A/B 活跃模型速度一致；普通会话绿色用标注为模拟的设备实际查看，空闲为 0、状态未知和各色优先级通过隔离测试。由于当前任务本身仍在运行，尚未在真实完全空闲的窗口看到归零。
- 本轮各架构安装材料位于 `target/tclash-dist-speed/`，已更新进 A 的安装模板及本机现有 Windows 1 迁移包；旧程序及旧迁移包保存在 `target/baseline-speed-refinement-20261113/`。Windows 安装及跨网效果仍待实机验收。当前机器的系统代理在重启前后均为关闭。
