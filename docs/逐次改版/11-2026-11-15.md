# 2026-11-15：Mac 2 标准安装器

- 用户要求 Mac 2 使用 macOS 标准安装器，并选择安装到“应用程序”目录；此前明确不在 A 所在的 Mac 1 上安装 Mac 2 包。已在本地生成独立 `.pkg`：`交付/Mac2标准安装包_20261115/Mac2_TClash_Preview.pkg`。安装到 `/Applications/TClash Preview.app`，沿用之前生成的 Mac 2 设备授权，包含该设备的私人令牌，仅可私下传送到 Mac 2；不要在 Mac 1 运行，也不要重新生成或撤销邀请。
- 安装前检查本机是否已有 A、其他设备身份、不同的待处理授权或旧连接；遇到冲突停止。若标准应用程序目录已有同身份 TClash，会先备份；若用户应用程序目录已有 TClash，为避免产生两个版本而停止并提示处理。安装后在当前登录用户下加载授权并启动程序，确认本地设备身份已写入后才处理可识别的旧 B 自动启动。A 与 Windows 设备配置未改动。
- 已从最终包重新解出并核对授权与 A 原发包完全一致，核对 A 端待接入邀请、设备令牌登记、仓库、签名验证者与加密接收者；无输出明文。包内主程序及安装辅助程序均为 Intel / Apple 芯片通用架构，主程序临时签名校验通过。模拟新设备安装、同身份重复安装、冲突保护及安装脚本的用户上下文和临时文件清理测试通过。
- 本机无 Apple Developer ID 安装器或应用证书；`.pkg` 未签名，程序为临时签名且未公证。`pkgutil --check-signature` 确认安装包无签名，不能称为已正式签名或保证 Gatekeeper 放行。未在 Mac 1 运行安装器；本机沙盒下 Installer 选项查询提示无法定位目标卷，Mac 2 的真实安装界面、自动启动和联网配对尚需目标设备实测。工具源码为 `tools/tclash-mac-pkg/`，没有推广到 A 端已有的后续设备包生成器。
