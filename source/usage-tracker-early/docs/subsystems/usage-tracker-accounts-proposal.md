# A 端多账号统计设计与验收

## 目标和范围

- 仅为 A 端本机增加多账号识别和查看。Codex 正常切换账号后，A 默认展示当前账号，并允许手动查看此前识别过的账号及各自周期。B 端采集及同步设置不因本项改变；新模板标明参考金额并非官方扣费。
- A 不修改 Codex 配置或登录状态，不代理 Codex 请求。账号标识、切换观察记录和统计结果只保存在 A 自己的数据目录；不保存、上传或复制 Codex 的登录凭据。
- 用户已确认按此方案开发。模拟账号切换与隔离副本中的历史记录对账通过；真实账号切换仍需用户正常切换时验收，不能声称已经完成实机验证。

## 改造前基线

- 改造前的 A 能读取本机当前账号和额度，但没有独立的账号选择器。设备 Token 和美元总计可能包含其他账号的记录；账号额度估算只计入能够归入所选账号的请求。
- 一个会话可能跨账号继续使用。会话创建时的账号标识只能证明创建者，不能证明会话中每次请求的实际账号。2026-11-06 的历史会话就是这种情况。
- 用户已确认当时从 Plus 账号切换到当前 Pro 账号。经逐条核对，197 条 Pro 请求已通过单条记录及额度事件校验补入当前账号；113 条 Plus 请求保留在原账号，不计入当前账号的额度估算。修正记录位于用量工具自己的配置中，不改变 Codex 日志或设置。
- [OpenAI 的 Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)列有读取当前账号和额度的方式，但并未保证每条历史请求都能获得实际账号标识。文档所述的认证变化通知也不能单独证明同类型账号之间的每次切换都已被观察到。

## 实际处理方式

1. A 每分钟只读观察 Codex 当前登录身份，账号变化时尝试读取一次该账号官方额度；手动读取时再次核对身份。只在 A 的独立数据目录保存不可逆账号标识、观察区间及额度读数。账户变更、读取失败、超过两分钟未观察或程序重启都会分开观察区间。不同凭据存储方式可能仍不可读取，用户可见“暂不可识别”。
2. 总览默认随当前账号切换，也可选择历史账号、「账号待确认」或「全部账号·日志总量」。单账号只计入该账号已确认及标注为观察推定的本机记录；其他账号和待确认不会混入。全部账号视图可核对所有原始 Token，按当前账号周期截取时不代表其他账号重置周期。真实 B 端记录的账号信息仍来自 B 的原有采集，A 无法替它证明切换后的逐条归属。
3. 单靠会话创建者、套餐或相同重置时间不足以确认请求属于哪个账号。程序只对请求的整个可见耗时位于同一观察区间、会话来源账号一致、请求 Token 与唯一额度事件匹配、且额度事件能对应唯一一个直接读取的账号周期的请求做「观察推定」。观察为定时采样，并非官方逐条账号凭证；短暂切换后又切回或进程保留旧凭据仍可能无法检测，界面明确标注推定。其他情况进入「待确认」；特别是 A 未运行、跨观察边界、无法唯一关联、缺少耗时或额度记录的请求。
4. 用户可在 A 端逐条确认本机待确认记录。确认保存请求指纹及其明确指定账号，重新读取时验证原始记录，日志不改写。历史 197 条 Pro 确认继续生效；用户确认切换前的 113 条 Plus 记录分别保存为单条确认，不凭一个时间段自动改写其他请求。
5. 账号凭据由 Codex 保管。文件、系统钥匙串或临时登录等不同存储方式需要分别验证；读取失败时显示无法确认，不能将其当作已退出或将数据归入其他账号。
6. 官方账号额度是该账号的共享读数，不能据此精确拆成每台设备、每个模型或项目的官方占比。模型美元是按参考价格换算，百分比是参考金额、系数和用户设定预算计算；两者均不是订阅的真实扣费或额度占比。$900 是用户设定的参考预算，并非 OpenAI 公布的 Pro 周额度。账户可能有多个官方额度桶，不能假设所有模型都按同一个桶计量。

OpenAI [额度接口](https://learn.chatgpt.com/docs/app-server)说明可读账号额度窗口、已用百分比与重置时间，以及部分账号 Token 活动数据；未提供设备、项目、模型或单次请求的官方订阅额度拆分。[官方价格说明](https://learn.chatgpt.com/docs/pricing)说明 API 价格和订阅用量是两种口径，不能据此推算订阅包含的任务用量。

## 验收条件

- 在隔离模拟环境中，从账号 A 切换到账号 B，再切回 A：A 自动显示当前账号，手动选择可看各自历史；账户数据不互相叠加。
- 同一会话跨账号使用时，能确认的请求分组正确；不能确认的请求进入待确认，切换附近的并发请求、A 离线期间及缺少额度事件的情况不得强行归属。
- 每个账号的 Token、模型、请求和估算金额可按原始记录对账；账号切换不改变总 Token、原始日志或既有人工确认记录。旧账号额度标明最后读取时间。
- 模拟断网、登录文件暂不可读、临时退出、相同套餐或相近重置时间，以及程序重启恢复；错误不能导致两账号用量合并。
- 用真实账号切换做一次验收前，只能宣称通过模拟测试。真实切换需用户在方便时配合；整个验证不由工具改动 Codex 登录或设置。
