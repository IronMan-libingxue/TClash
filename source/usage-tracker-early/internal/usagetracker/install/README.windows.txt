Codex 用量 · Windows 采集端

1. 将整个压缩包私下传到 Windows 电脑，完整解压到一个文件夹。
2. 双击文件夹里的 Install.cmd，等待 Codex 用量窗口打开。
3. 这台 Windows 使用你自己的 Codex 和订阅账号。安装程序不会改动 Codex 配置，也不会让 Codex 走代理。
4. 安装后会在当前 Windows 账号登录时自动启动。关闭窗口后程序会继续在通知区域采集；在通知区域菜单选择退出可停止采集。
5. 设备联网时首次自动接入，之后默认每 5 分钟上传一次。A 端从同一个私有仓库读取。首次回填、断网或电脑休眠可能需要更长时间。

本安装包包含专用于同步仓库的访问凭据，请只通过可信方式传给自己的设备，不要公开或转发。用量数据加密后同步，不上传对话正文。
本程序是本机编译的试用版，尚未经过 Windows 实机验收；安装后请与 Mac 上的 A 端一起核对数据和同步状态。
